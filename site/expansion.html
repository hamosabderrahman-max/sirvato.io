Domain 05 — EXPANSION

EXPANSION

The growth layer. EXPANSION defines how SIRVATO scales without losing coherence.

Premise

Every system that cannot grow is already dying. EXPANSION is SIRVATO's answer to scale.

It does not add complexity. It adds capacity while preserving Unità.

Expansion Vectors

1. Content Expansion

Adding new Markdown files to /content/ and registering them in sirvato.config.json is sufficient to expand the site. The builder handles the rest.

2. Domain Expansion

New domains can be introduced only when they satisfy all three pillars of SUPERFORMA:

  • Unità — the new domain integrates without contradiction
  • Presenza — it has a clear, visible role
  • Operatività — it enables immediate action

3. Structural Expansion

New folders or structural changes require explicit authorization by SIRVATO's Super-Forma. They are not introduced speculatively.

Expansion Protocol

  1. Define the new domain or page in sirvato.config.json
  2. Create the corresponding Markdown source in /content/
  3. Run the builder — the site regenerates automatically
  4. Validate against SUPERFORMA before publishing

Constraints

  • Expansion never breaks existing pages.
  • Expansion never introduces orphaned content.
  • Expansion never violates the design system.
  • Every addition is justified by operational need.

SIRVATO grows when it must. Never because it can.
